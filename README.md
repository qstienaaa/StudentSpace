# StudentSpace

## Project Description
StudentSpace is a simple student management website designed to manage student information, courses, academic results and performance analytics in one platform.

## Features
- Admin Login System
- Dashboard with summary information
- Student Information Management
- Course Information
- Student Academic Results
- Performance Analytics with Charts
- Admin Profile
- Announcements
- Responsive design for desktop and mobile devices
